# แดชบอร์ดเฝ้าระวัง 10 โรค จังหวัดอุบลราชธานี กลุ่มงานควบคุมโรคติดต่อ สำนักงานสาธารณสุขจังหวัดอุบลราชธานี เว็บไซต์นี้เป็นไฟล์ HTML/CSS/JS ล้วน ใช้ GitHub Pages ได้ฟรี ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` เป็นไฟล์ `.csv` และ `.json` > คู่มือฉบับเต็มสำหรับผู้ดูแล (ไม่แสดงในแดชบอร์ด) เปิดที่ `tools/guide.html` หรือดูด้านล่าง ## โครงสร้างไฟล์ ``` index.html หน้าแดชบอร์ด css/style.css สี ฟอนต์ ขนาด (สีหลักอยู่บรรทัดแรก :root) js/ การทำงานและสูตรคำนวณ (ไม่ต้องแก้ในการอัปเดตปกติ) app.js หน้าต่างๆ ของแดชบอร์ด data.js อ่านไฟล์ สูตรคำนวณ ตรวจความถูกต้องของข้อมูล charts.js กราฟ map.js แผนที่ infographic.js ภาพ Info xlsx-lite.js อ่านไฟล์ Excel/Word ในเบราว์เซอร์ guide.js หน้าคู่มือ assets/ โลโก้ และรูปบุคลากร (assets/people/) tools/update.html ศูนย์อัปเดตข้อมูล (ใช้ทุกวันจันทร์) tools/convert.html รวม & แปลงไฟล์ DDS รายเคส (เลือกได้หลายไฟล์) tools/guide.html คู่มือผู้ดูแล (ไม่มีลิงก์จากแดชบอร์ด) data/ ข้อมูลทั้งหมด ← อัปโหลดไฟล์ทับที่นี่ .nojekyll ไฟล์ว่าง ห้ามลบ (ให้ GitHub Pages แสดงไฟล์ตามจริง) ``` ## เผยแพร่ครั้งแรก 1. github.com → **New repository** → ตั้งชื่อ เช่น `ubon-10-diseases` → **Public** → Create 2. **uploading an existing file** → ลากทุกไฟล์และโฟลเดอร์ในโฟลเดอร์นี้ (ต้องเห็น `index.html` ชั้นบนสุด) → **Commit changes** 3. **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save 4. รอ 1–3 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/ubon-10-diseases/` → ใส่ลิงก์นี้ใน `data/config.json` ช่อง `dashboard_url` ## อัปเดตทุกวันจันทร์ 1. อัปเดตชีต **สถานการณ์ 10 โรค** ใน Excel "รวบรวมรายงาน" (ใส่วันที่ข้างคำว่า อัพเดต) 2. Export DDS รายเคส 1 ม.ค. – วันปัจจุบัน (ได้หลายไฟล์ ไฟล์ละ 10,000 แถว) 3. เปิด `tools/update.html` - ข้อ 1: เลือกไฟล์ Excel → ดาวน์โหลด `summary_province.csv` (และ `dds_district.csv` ถ้ามีชีตผลงาน DDS) - ข้อ 2: เปิดเครื่องมือรวมไฟล์ DDS → เลือก**ทุกไฟล์พร้อมกัน** → ดาวน์โหลด `weekly_25xx.csv`, `dds_status.csv`, `unit_quality.csv` - ข้อ 3 (ถ้ามีเหตุการณ์ใหม่): OutbreakVerificationList.docx → `mebs_events.csv` - ข้อ 4 (เดือนละครั้ง): Export จาก DDC Dashboard หน้า 1 — ตารางรายสถานพยาบาล + ตารางสรุปตามประเภท (เลือกพร้อมกัน) → `facility_dds.csv`, `facility_types.csv` - ผลงาน อปท. รายหน่วย: กรอง ประเภทสถานบริการ = "ศูนย์บริการสาธารณสุข อปท." แล้ว Export ตารางรายสถานพยาบาลอีกไฟล์ ใส่ชื่อประเภทในช่อง แล้วเลือกไฟล์ → ระบบติดป้าย อปท. ให้ 4. GitHub → โฟลเดอร์ `data` → **Add file → Upload files** → ลากไฟล์ทั้งหมด → **Commit changes** 5. รอ 1–3 นาที → Ctrl+F5 → หน้า **คุณภาพข้อมูล** ต้องไม่มีรายการสีแดง → หน้า **สร้างภาพ Info** ดาวน์โหลดภาพส่งพื้นที่ **ห้ามอัปโหลดไฟล์ DDS / Excel / Word ต้นฉบับขึ้น GitHub** (repo แบบ Public ทุกคนเห็นได้) อัปโหลดเฉพาะ `.csv` ที่ได้จากเครื่องมือ ซึ่งเป็นข้อมูลสรุปไม่มีข้อมูลรายบุคคล ## จุดที่แก้ไขได้เอง (ไม่ต้องเขียนโค้ด) | อยากเปลี่ยน | ไฟล์ | ตำแหน่ง / ตัวอย่าง | |---|---|---| | ประชากรจังหวัด | `data/config.json` | `"population_total": 1856713` | | ประชากรรายอำเภอ | `data/districts.csv` | คอลัมน์ `population` ให้ครบ 25 อำเภอ | | เกณฑ์สีเตือนภัย | `data/config.json` | `"alert": { "ratio_yellow": 1.0, "ratio_orange": 1.5, "ratio_red": 2.0 }` | | เกณฑ์คุณภาพ DDS | `data/config.json` | `"dds_kpi": { "coverage_target": 100, "timely_target": 80, "pending_max": 1, "zero_report_target": 60 }` | | มาตรการแต่ละโรค | `data/config.json` | ใน `"diseases"` → `"measures": ["ข้อ 1", "ข้อ 2"]` | | รหัสโรค 506 / คำค้นชื่อโรค | `data/config.json` | `"codes506": ["26","27","66"]`, `"keywords": [...]` | | เพิ่มปีงบใหม่ | `data/config.json` | `"weekly_files": ["data/weekly_2569.csv", "data/weekly_2570.csv", "data/weekly_2571.csv"]` | | ลิงก์บนภาพ Info | `data/config.json` | `"dashboard_url": "https://ชื่อผู้ใช้.github.io/ubon-10-diseases/"` | | รูปบุคลากร | `assets/people/` + `data/contacts.csv` | อัปโหลด `person-1.jpg` แล้วใส่ชื่อไฟล์ในคอลัมน์ `photo` ของแถวนั้น | | ผู้ประสาน / วิธีแก้ปัญหา | `data/contacts.csv`, `data/troubleshoot.csv` | แก้ใน Excel แล้วบันทึกเป็น CSV UTF-8 | | สีหลักของระบบ | `css/style.css` | บรรทัดบนสุด `:root { --navy: #10234A;
