# แดชบอร์ดเฝ้าระวัง 10 โรค จังหวัดอุบลราชธานี

กลุ่มงานควบคุมโรคติดต่อ สำนักงานสาธารณสุขจังหวัดอุบลราชธานี

เว็บไซต์ HTML/CSS/JS ล้วน เผยแพร่ด้วย GitHub Pages ข้อมูลทั้งหมดอยู่ใน `data/` และเป็น **ยอดรวมเท่านั้น** ไม่มีข้อมูลรายบุคคล

## แหล่งข้อมูล
| ข้อมูล | ไฟล์ | ที่มา | รอบอัปเดต |
|---|---|---|---|
| ยอดรวมจังหวัด ปีปัจจุบัน | summary_province.csv | Excel รวบรวมรายงาน สสจ. | ทุกวันจันทร์ |
| รายอำเภอรายสัปดาห์ / ตำบล / อายุ / กลุ่มก้อน | district_week, tambon_year, age_province, district_deaths, clusters, dds_meta | DDS (ประมวลผลในเครื่องเจ้าหน้าที่) | ทุกวันจันทร์ (ไฟล์แรก) / ทั้งปีทุก 3 เดือน |
| ตารางรายอำเภอ | district_ddc.csv | แดชบอร์ดกองระบาดวิทยา | ทุก 4 สัปดาห์ |
| มัธยฐาน 5 ปี ประเทศ/เขต/จังหวัด | baseline_ddc.csv | แดชบอร์ดกองระบาดวิทยา | ปีละครั้ง (อัปเดตวันที่ใน config: ddc_base_as_of) |

## อัปเดตประจำสัปดาห์
1. เปิด `ศูนย์อัปเดต.html` **ในเครื่องเจ้าหน้าที่** (ไฟล์นี้ไม่อยู่ใน repo)
2. ใส่ Excel + ไฟล์ DDS → ผ่านด่านตรวจ → ดาวน์โหลด zip
3. แตก zip → อัปโหลดไฟล์ทับใน `data/` (Add file → Upload files → Commit)
4. ลบไฟล์ DDS ออกจากเครื่อง

## ห้ามอัปโหลด
ไฟล์ DDS รายเคส, Excel/Word ที่มีชื่อผู้ป่วย, รูปภาพบุคคล, ไฟล์ `ศูนย์อัปเดต.html`
