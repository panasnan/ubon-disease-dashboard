# แดชบอร์ดเฝ้าระวัง 10 โรค จังหวัดอุบลราชธานี

กลุ่มงานควบคุมโรคติดต่อ สำนักงานสาธารณสุขจังหวัดอุบลราชธานี

เว็บไซต์นี้เป็นไฟล์ HTML/CSS/JS ล้วน ใช้ GitHub Pages ได้ฟรี ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` เป็นไฟล์ `.csv` และ `.json`

> คู่มือฉบับเต็มสำหรับผู้ดูแล (ไม่แสดงในแดชบอร์ด) เปิดที่ `tools/guide.html` หรือดูด้านล่าง

## โครงสร้างไฟล์

```
index.html            หน้าแดชบอร์ด
css/style.css         สี ฟอนต์ ขนาด (สีหลักอยู่บรรทัดแรก :root)
js/                   การทำงานและสูตรคำนวณ (ไม่ต้องแก้ในการอัปเดตปกติ)
  app.js              หน้าต่างๆ ของแดชบอร์ด
  data.js             อ่านไฟล์ สูตรคำนวณ ตรวจความถูกต้องของข้อมูล
  charts.js           กราฟ      map.js  แผนที่      infographic.js  ภาพ Info
  xlsx-lite.js        อ่านไฟล์ Excel/Word ในเบราว์เซอร์     guide.js  หน้าคู่มือ
assets/               โลโก้ และรูปบุคลากร (assets/people/)
tools/update.html     ศูนย์อัปเดตข้อมูล (ใช้ทุกวันจันทร์)
tools/convert.html    รวม & แปลงไฟล์ DDS รายเคส (เลือกได้หลายไฟล์)
tools/guide.html      คู่มือผู้ดูแล (ไม่มีลิงก์จากแดชบอร์ด)
data/                 ข้อมูลทั้งหมด ← อัปโหลดไฟล์ทับที่นี่
.nojekyll             ไฟล์ว่าง ห้ามลบ (ให้ GitHub Pages แสดงไฟล์ตามจริง)
```

## เผยแพร่ครั้งแรก

1. github.com → **New repository** → ตั้งชื่อ เช่น `ubon-10-diseases` → **Public** → Create
2. **uploading an existing file** → ลากทุกไฟล์และโฟลเดอร์ในโฟลเดอร์นี้ (ต้องเห็น `index.html` ชั้นบนสุด) → **Commit changes**
3. **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save
4. รอ 1–3 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/ubon-10-diseases/` → ใส่ลิงก์นี้ใน `data/config.json` ช่อง `dashboard_url`

## อัปเดตทุกวันจันทร์

1. อัปเดตชีต **สถานการณ์ 10 โรค** ใน Excel "รวบรวมรายงาน" (ใส่วันที่ข้างคำว่า อัพเดต)
2. Export DDS รายเคส 1 ม.ค. – วันปัจจุบัน (ได้หลายไฟล์ ไฟล์ละ 10,000 แถว)
3. เปิด `tools/update.html`
   - ข้อ 1: เลือกไฟล์ Excel → ดาวน์โหลด `summary_province.csv` (และ `dds_district.csv` ถ้ามีชีตผลงาน DDS)
   - ข้อ 2: เปิดเครื่องมือรวมไฟล์ DDS → เลือก**ทุกไฟล์พร้อมกัน** → ดาวน์โหลด `weekly_25xx.csv`, `dds_status.csv`, `unit_quality.csv`
   - ข้อ 3 (ถ้ามีเหตุการณ์ใหม่): OutbreakVerificationList.docx → `mebs_events.csv`
   - ข้อ 4 (เดือนละครั้ง): Export จาก DDC Dashboard หน้า 1 — ตารางรายสถานพยาบาล + ตารางสรุปตามประเภท (เลือกพร้อมกัน) → `facility_dds.csv`, `facility_types.csv`
     - ผลงาน อปท. รายหน่วย: กรอง ประเภทสถานบริการ = "ศูนย์บริการสาธารณสุข อปท." แล้ว Export ตารางรายสถานพยาบาลอีกไฟล์ ใส่ชื่อประเภทในช่อง แล้วเลือกไฟล์ → ระบบติดป้าย อปท. ให้
4. GitHub → โฟลเดอร์ `data` → **Add file → Upload files** → ลากไฟล์ทั้งหมด → **Commit changes**
5. รอ 1–3 นาที → Ctrl+F5 → หน้า **คุณภาพข้อมูล** ต้องไม่มีรายการสีแดง → หน้า **สร้างภาพ Info** ดาวน์โหลดภาพส่งพื้นที่

**ห้ามอัปโหลดไฟล์ DDS / Excel / Word ต้นฉบับขึ้น GitHub** (repo แบบ Public ทุกคนเห็นได้) อัปโหลดเฉพาะ `.csv` ที่ได้จากเครื่องมือ ซึ่งเป็นข้อมูลสรุปไม่มีข้อมูลรายบุคคล

## หลักการคำนวณ

- ภาพรวมจังหวัด (ปีปฏิทิน) ใช้ตัวเลขรายงานประจำสัปดาห์จาก Excel (`config.json` → `province_source`) ส่วนรายอำเภอ แนวโน้ม สถานะสี และกลุ่มก้อน ใช้ DDS รายเคส เฉพาะรายงาน "อนุมัติแล้ว" ของผู้ป่วยที่จังหวัดขณะป่วยเป็นอุบลฯ
- อัตราป่วย = ผู้ป่วย ÷ ประชากร × 100,000 (คำนวณใหม่ทุกครั้ง ไม่ใช้ค่าที่พิมพ์ในชีต) • CFR = ตาย ÷ ป่วย × 100
- สัปดาห์ระบาดวิทยาเริ่มวันอาทิตย์ ปีงบ/ปีปฏิทินนับตามวันเริ่มป่วย
- สถานะสี: ผู้ป่วย 4 สัปดาห์ล่าสุดเทียบค่ามัธยฐาน 5 ปี (ต้องมีข้อมูลย้อนหลัง) — เกณฑ์แก้ได้ใน `config.json` → `alert`
- คุณภาพ DDS ตามเกณฑ์กองระบาด: ทันเวลา > 80%, รอแก้ไข < 1%, ส่งต่อเนื่อง ≥ 60% — แก้ได้ใน `config.json` → `dds_kpi`
