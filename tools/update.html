คู่มือผู้ดูแลแดชบอร์ด

🔒 ไฟล์ที่ได้เป็นข้อมูลสรุป ไม่มีชื่อ เลขบัตร อายุ หรือรายละเอียดอาการรายบุคคล จึงอัปโหลดขึ้น GitHub ได้

1ไฟล์ Excel "รวบรวมรายงาน" ทุกวันจันทร์

อ่านชีต สถานการณ์ 10 โรค (ใช้ทุกสัปดาห์) และถ้ามี จะอ่านชีต ผลงาน DDS ในและนอกสังกัด / ผลงาน DDS อปท. ด้วย

2ไฟล์ DDS รายเคส (D506) ทุกวันจันทร์

ใช้สำหรับแผนที่ รายอำเภอ แนวโน้ม และกลุ่มก้อน — เปิดเครื่องมือรวมไฟล์ DDS (เลือกได้หลายไฟล์พร้อมกัน)

เปิดเครื่องมือรวม & แปลงไฟล์ DDS →

3Outbreak Verification List (.docx) เมื่อมีเหตุการณ์ใหม่

ดึงเฉพาะข้อมูลระดับเหตุการณ์ (โรค จำนวนป่วย/ตาย พื้นที่ วันเริ่มป่วย แหล่งข่าว การดำเนินการ สถานะ) — ไม่ดึง อายุ เพศ โรคประจำตัว หรืออาการรายบุคคล

5ทะเบียนผู้เสียชีวิต (รายงานด้วยตนเอง ก่อนคีย์ DDS) เมื่อมีรายงานผู้เสียชีวิต

ใช้เมื่อได้รับแจ้งผู้เสียชีวิตแล้ว แต่พื้นที่ยังไม่ได้คีย์ใน DDS — แดชบอร์ดจะนับรวมให้ และแสดงรายการรอคีย์จนกว่าจะติ๊ก "คีย์ใน DDS แล้ว" ห้ามใส่ชื่อ เลขบัตร HN หรือที่อยู่บ้านเลขที่

4ความครอบคลุม/ทันเวลารายสถานพยาบาล (Export จาก DDC Dashboard) เดือนละครั้ง

เลือกได้หลายไฟล์พร้อมกัน ระบบแยกให้เอง: (ก) ตารางรายสถานพยาบาล (คอลัมน์ อำเภอ, สถานพยาบาล, รายงานแล้ว, รายงานทันเวลา (7 วัน) (n) ...) และ (ข) ตารางสรุปตามประเภทสถานพยาบาล (โรงพยาบาลศูนย์ ... ศูนย์บริการสาธารณสุข อปท.)

⭐ ผลงาน อปท. รายหน่วย: ใน DDC Dashboard เลือกตัวกรอง ประเภทสถานบริการ = ศูนย์บริการสาธารณสุข อปท. แล้ว Export ตาราง (ก) อีกไฟล์ → ใส่ชื่อประเภทในช่องด้านล่าง → ระบบจะติดป้าย "อปท." ให้หน่วยเหล่านั้น และคำนวณความทันเวลาของ อปท. รายอำเภอจากข้อมูลดิบ
